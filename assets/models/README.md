# 3D Custom Model Guide

To display your personalized 3D avatar / 3D model:
1. Place your 3D model file named `avatar.glb` in this directory (`Portfolio/assets/models/avatar.glb`).
2. The portfolio's `js/scene3d.js` will automatically detect and render your custom 3D model inside the interactive Three.js scene!
3. If no `avatar.glb` is present, the portfolio automatically defaults to the futuristic holographic data core & constellation network.
